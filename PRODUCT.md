## Platform

web

## Stack

Astro — static site generation for a content-heavy subtitle release site.

## Users

Indonesian-speaking fans of Sakurazaka46 who want to watch the group's variety and documentary content with accurate Indonesian subtitles. They arrive knowing which show or episode they want; their job is to find and download the subtitle file quickly.

Secondary audience: developers or translators curious about the AI-assisted subtitle pipeline behind the releases, reached via the About/Algorithm page.

## Product Purpose

HikaLeonSubs is a fansub release site for Indonesian subtitles of Sakurazaka46 content. It lets Indonesian fans access variety shows, music channel clips, and documentaries that would otherwise be language-locked. It also documents the open-source AI pipeline used to produce those subtitles, so others can replicate or build on it.

## Positioning

The only dedicated Indonesian subtitle source for Sakurazaka46's full content slate, produced through a documented, reproducible AI pipeline that subtitlers can fork and improve — not just a file dump.

## Operating Context

Users land on a show or episode page, check episode availability, and download a subtitle file to use in their local media player. The GitHub documentation is linked from a single "About" or "Algorithm" page and does not need to be reproduced inline — a clear explanation and pointer is sufficient.

Content covered: Sokomagattara, Sakurazaka? · Sakurazaka Channel · Chokosaku · Sakura Meets · Documentary — and any future Sakurazaka46 productions.

## Capabilities and Constraints

- Subtitle release site only; no video hosting or in-browser playback.
- Logo asset exists; typography and visual identity are greenfield.
- AI pipeline documentation lives externally on GitHub; the site links to it with a brief explanation on one page.
- No special accessibility standard confirmed beyond reasonable web defaults.

## Product Principles

1. **Fans first, friction last.** Finding and downloading a subtitle file must take as few steps as possible.
2. **Honest provenance.** The AI pipeline is documented openly; the site never obscures how subs are made.
3. **Content, not chrome.** The show catalog and episode list are the product; the interface recedes behind them.
4. **Grow with the group.** The catalog model must accommodate new Sakurazaka46 productions without structural rework.
5. **Community handoff.** The pipeline documentation exists so others can reproduce or extend the work independently.
